# Модуль формирования заказов медицинской лаборатории

## Описание
Модуль предназначен для создания и управления заказами на медицинские исследования в лаборатории. Система позволяет регистрировать пациентов, добавлять услуги, генерировать штрих-коды и создавать PDF-документы.

## Основные функции

### 1. Управление заказами
- Создание нового заказа
- Регистрация пациента
- Добавление медицинских услуг
- Генерация штрих-кода пробы
- Создание PDF-документа с результатами

### 2. Работа с пациентами
- Регистрация нового пациента
- Поиск существующих пациентов
- Хранение контактной информации
- История заказов пациента

### 3. Управление услугами
- Добавление услуг в заказ
- Автоматический расчет стоимости
- Категоризация услуг
- Управление прайс-листом

### 4. Генерация документов
- Создание штрих-кодов для проб
- Формирование PDF-документов
- Печать результатов исследований

## Основные функции модуля

### Работа с заказами
- `create_order()` - создание нового заказа
- `process_tube_code()` - обработка и валидация кода пробы
- `add_service_to_order()` - добавление услуги в заказ
- `calculate_total_cost()` - расчет общей стоимости заказа
- `generate_order_pdf()` - генерация PDF-документа заказа
- `print_order()` - печать заказа

### Работа с пациентами
- `register_patient()` - регистрация нового пациента
- `search_patient()` - поиск пациента по ФИО или телефону
- `update_patient_info()` - обновление информации о пациенте
- `get_patient_history()` - получение истории заказов пациента
- `validate_patient_data()` - проверка данных пациента

### Работа с услугами
- `add_service()` - добавление новой услуги
- `update_service_price()` - обновление стоимости услуги
- `categorize_services()` - категоризация услуг
- `get_service_list()` - получение списка доступных услуг
- `calculate_service_cost()` - расчет стоимости услуги

### Работа с документами
- `generate_barcode()` - генерация штрих-кода для пробы
- `create_pdf_report()` - создание PDF-отчета
- `print_document()` - печать документа
- `save_document()` - сохранение документа
- `export_to_pdf()` - экспорт данных в PDF

## Технические детали

### База данных
- Таблица `patients` - информация о пациентах
- Таблица `services` - список доступных услуг
- Таблица `orders` - информация о заказах
- Таблица `order_services` - связи заказов с услугами

### Интерфейс
- Главное окно заказа (`OrderWindow`)
- Диалог пациента (`PatientDialog`)
- Диалог выбора услуг (`ServiceDialog`)
- Диалог предупреждений (`WarningDialog`)

### Стилизация
- Основной цвет: #497C51 (зеленый)
- Дополнительный цвет: #76E383 (светло-зеленый)
- Фон: #FFFFFF (белый)
- Текст: #000000 (черный)
- Цвет ошибок: #F44336 (красный)
- Цвет успеха: #4CAF50 (зеленый)
- Шрифт: Comic Sans MS
- Размер шрифта: 12pt
